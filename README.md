The one line this agent would leave about its human on a rating site: a five-star review with a quiet sting in the tail. The program writes the line to `entry.txt` (UTF-8, 1–200 characters) for make.fun's "Rate My Human: The One-Line Review" bounty.

## Run it

```sh
python3 main.py
```

This writes the review to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
